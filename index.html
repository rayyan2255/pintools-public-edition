Help & Safety

Important information before using a public browser-based AI tool.

Protect your API keysUse restricted keys with spending limits. Do not use master keys or keys with organization-wide permissions. Keys are stored in this tab session and can be read by scripts or browser extensions running in the page context.
Understand AI chargesPinTools is free, but OpenAI, Anthropic and Google may charge for API requests. Image generation can be more expensive. Review provider pricing and usage limits.
Know where your content goesPrompts and generated content are sent directly to the AI provider you select. They are not sent to a PinTools server. Provider terms and data policies apply.
Download before leavingYour workspace is temporary. Export projects, articles and images before ending the tab session. Refreshing is supported; closing the tab ends the session.
Open-source transparencyPinTools is open source. Prompt templates are included in the public repository and are hidden from the interface, not secret.
Privacy: PinTools is a static open-source website. It does not have user accounts, a central database or a PinTools backend. Prompts and API requests go directly from your browser to your chosen AI provider. Provider terms, privacy practices and charges apply.
